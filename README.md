## 🎥Stream Vibe  

A multi-page streaming service application with fully featured pages, complex UI components, and responsive design.

### 🔗Demo  
[Open the project on Vercel]

### 📌**Functionality**  
- **Home**
- **Movies & Shows**
- **Movie Open**
- **Show Open** 
- **Support** 
- **Subscription** 

### 🚀**Technologies**  
- **Vanilla JavaScript** — implementation of interactive components 
- **SCSS (Sass)** — application styling  
- **Vite + Minista** — project build and static page generation  
- **BEM** — class naming methodology  
- **Swiper** — slider implementation  
- **IMask** — input masks for forms 

### 🛠️**Setup and running the project**  

#### 1️⃣Clone the repository:  
```bash
git clone git@github.com:therelyona/stream-vibe.git
```

#### 2️⃣Navigate to the project directory:
```bash
cd stream-vibe
```

#### 3️⃣Install dependencies:
```bash
npm install
```

#### 4️⃣For local development:
```bash
npm run start
```

#### 5️⃣To build the project:
```bash
npm run build
```

#### 6️⃣To preview the built project:
```bash
npm run preview
```
